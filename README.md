# Курс мінної безпеки

Інтерактивний навчальний веб-додаток для вивчення правил мінної безпеки з можливістю проходження тестування та отримання сертифіката.

## Опис проєкту

Цей навчальний курс створено для ознайомлення користувачів різних вікових категорій з основами мінної безпеки. Додаток містить три рівні складності з адаптованими питаннями та детальними поясненнями.

## Функціональні можливості

- **Три рівні навчання:**
  - Рівень 1: Загальна безпека (Основи)
  - Рівень 2: Поведінка при виявленні ВНП (Алгоритми)
  - Рівень 3: Наслідки та допомога (Перша допомога)

- **Вікові категорії:**
  - Молодша школа (1-4 класи)
  - Середня школа (5-9 класи)
  - Старша школа (10-11 класи / Дорослі)

- **Інтерактивні елементи:**
  - Питання з варіантами відповідей
  - Ілюстрації до питань
  - Миттєвий зворотний зв'язок
  - Детальні пояснення до кожної відповіді
  - Прогрес-бар для відстеження виконання

- **Система оцінювання:**
  - Підрахунок балів за правильні відповіді
  - Відстеження статистики проходження
  - Збереження прогресу в локальному сховищі браузера

- **Генерація документів:**
  - Завантаження звіту про проходження курсу (PDF)
  - Завантаження сертифіката після успішного завершення всіх рівнів (PDF)

## Структура файлів

## Як користуватися

1. **Запуск додатку:**
   - Відкрийте файл `project.html` у веб-браузері
   - Рекомендовані браузери: Google Chrome, Mozilla Firefox, Microsoft Edge

2. **Початок роботи:**
   - Введіть своє ім'я або псевдонім
   - Оберіть вікову категорію
   - Натисніть кнопку "Почати навчання →"

3. **Проходження тестування:**
   - Оберіть рівень для проходження
   - Уважно читайте питання та оглядайте ілюстрації
   - Обирайте один варіант відповіді
   - Після вибору отримаєте пояснення
   - Натискайте "Наступне питання →" для продовження

4. **Перегляд результатів:**
   - Після завершення рівня переглянете детальні підсумки
   - Можете повторно пройти рівень для покращення результату
   - Переходьте до наступного рівня

5. **Отримання документів:**
   - Після проходження рівня можете завантажити PDF-звіт
   - Після завершення всіх трьох рівнів з'явиться можливість завантажити сертифікат

6. **Збереження прогресу:**
   - Натисніть "💾 Зберегти прогрес" у головному меню
   - Прогрес автоматично зберігається після кожного рівня
   - При повторному відкритті сторінки прогрес відновиться автоматично

## Технічні вимоги

- Сучасний веб-браузер з підтримкою JavaScript
- З'єднання з Інтернетом (для завантаження шрифтів та бібліотек)
- Рекомендована роздільна здатність екрану: 1024×768 або вище

## Використані технології

- **HTML5** — структура сторінки
- **CSS3** — оформлення та адаптивний дизайн
- **JavaScript (ES6+)** — логіка додатку
- **jsPDF** — генерація PDF-документів
- **html2canvas** — конвертація HTML в зображення для PDF
- **LocalStorage API** — збереження прогресу користувача

## Додавання власних питань

Для додавання нових питань відредагуйте файл `questions.js`:

```javascript
{
    text: "Текст питання?",
    img: "img/назва-файлу.jpg",  // Опціонально
    options: ["Варіант 1", "Варіант 2", "Варіант 3", "Варіант 4"],
    correct: 1,  // Індекс правильної відповіді (починаючи з 0)
    explanation: "Пояснення правильної відповіді"
}
```

### Додавання зображень до питань

1. **Створіть папку для зображень:**
   - Створіть папку `img` в корені проєкту (якщо її ще немає)
   - Структура: `pdf-generator/img/`

2. **Підготуйте зображення:**
   - Рекомендовані формати: JPG, PNG, WebP
   - Рекомендований розмір: не більше 800×600 пікселів
   - Оптимізуйте розмір файлу (до 500 KB) для швидкого завантаження

3. **Додайте зображення до питання:**
   ```javascript
   {
       text: "Що таке міна чи граната?",
       img: "img/1-child.jpg",  // Шлях до зображення
       options: ["Варіант 1", "Варіант 2", "Варіант 3", "Варіант 4"],
       correct: 1,
       explanation: "Пояснення"
   }
   ```

4. **Зображення буде відображатися:**
   - Під текстом питання
   - З округленими кутами
   - З синьою рамкою
   - Максимальна ширина 500px

**Приклад структури файлів:**
```
pdf-generator/
├── img/
│   ├── 1-child.jpg
│   ├── 2-teen.jpg
│   └── 3-adult.png
├── index.html
└── questions.js
```

## Зміна теоретичного PDF-файлу

1. **Підготуйте PDF-документ:**
   - Створіть або оновіть теоретичний матеріал з мінної безпеки
   - Збережіть файл у форматі PDF

2. **Додайте файл до проєкту:**
   - Створіть папку `docs` в корені проєкту (якщо її немає)
   - Помістіть ваш PDF-файл у папку `docs`
   - Назвіть файл `theory.pdf`

3. **Структура файлів:**
   ```
   pdf-generator/
   ├── docs/
   │   └── theory.pdf    # Ваш теоретичний матеріал
   ├── index.html
   ├── script.js
   └── questions.js
   ```

4. **Використання іншого імені файлу:**
   Якщо ви хочете використати інше ім'я файлу, відредагуйте `script.js`:
   ```javascript
   function openTheory() {
       window.open('docs/ваша-назва.pdf', '_blank');
   }
   ```

5. **Зміст теоретичного PDF:**
   Рекомендується включити:
   - Основні правила безпеки в мінонебезпечних зонах
   - Ілюстрації типів ВНП (вибухонебезпечних предметів)
   - Алгоритм дій при виявленні підозрілих предметів
   - Номери екстрених служб (101, 102, 112)
   - Правила надання першої допомоги
   - Інформацію адаптовану для різних вікових категорій
